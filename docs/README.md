# AegiSec2 Documentación

Bienvenido a la documentación oficial del proyecto **AegiSec2**. 

## Estructura del Proyecto

El proyecto está dividido en varios componentes principales:

1. **`server/`**: Contiene la infraestructura central, como el backend, el dashboard (interfaz principal), certificados SSL (`certs`) y la configuración de contenedores de Docker (`docker`, `docker-compose.yml`).
2. **`agent/`**: Contiene el código o cliente del agente que se ejecuta en las máquinas o nodos vigilados por AegiSec2.
3. **`landing/`**: Contiene el código fuente de la Landing Page principal (orientada a despliegues en la nube, como AWS S3 o Vercel).
4. **`docs/`**: Contiene los manuales y arquitectura técnica detallada.
